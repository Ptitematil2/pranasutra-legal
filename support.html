Oracle Pranasutra

Assistance

Oracle Pranasutra est une application de tirage de cartes oracle : chaque jour, un rituel de mélange, puis un tirage, avec un message et un exercice d'ancrage.

Questions fréquentes

Je ne peux tirer qu'une carte par jour ?

Oui, c'est volontaire : un tirage par jour, de minuit à minuit. Vous pouvez recharger de l'Énergie pour un tirage supplémentaire dans la journée.

Le widget « carte du jour » n'affiche rien.

Ajoutez le widget depuis l'écran d'accueil (appui long → « + » → Pranasutra). S'il reste vide, redémarrez l'iPhone : le service de widgets d'iOS se rafraîchit alors.

J'ai changé d'iPhone, où est mon solde d'Énergie ?

Le solde est lié à votre compte iCloud et se resynchronise automatiquement. Vos achats peuvent être restaurés depuis l'écran de recharge.

Mon historique a disparu.

L'historique est stocké uniquement sur l'appareil. Le désinstaller efface définitivement ces données.
